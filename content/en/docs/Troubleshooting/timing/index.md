## Prerequisite

**After checking the thread path, needle orientation, and other common causes, a small number of machines may have a timing issue.**  
**This problem is most likely to occur after a severe bird’s nest or thread jam.**

---

## 1. Symptoms

If you observe any of the following, and thread path, needle direction, and tension are already confirmed correct:

- **Frequent needle breaks** (bent or broken needle tips)
- **Rotary hook fails to catch the upper thread loop** (skipped stitches)
- **Bobbin thread cannot be picked up** (loops not formed)

If these symptoms persist despite correct thread path and needle orientation, check the timing.

## 2. Confirmation

1. **Manually rotate the main shaft to the 202° mark** (refer to the scale or encoder mark on your machine).
2. **Observe the position of the rotary hook tip relative to the needle**:
   - Correct position: The hook tip must **align with the center of the needle eye**, with a clearance of approximately 0.5–1.0 mm.
   - If misaligned (early or late), the timing is incorrect.
3. **Inspect the hook tip for damage** – replace it first if damaged.

---

## 3. Correction

1. **Loosen the set screws on the rotary hook drive gear **.
2. **Fine‑adjust the hook shaft** so that the hook tip aligns precisely with the center of the needle eye at the 202° position.
3. **Tighten the screws to the specified torque**.
4. **Manually rotate the main shaft one full revolution** to confirm there is no interference and that the 202° position remains correct.
5. **Re‑thread the machine, install a new needle**, and run a test pattern.

If the needle breaks and thread pickup issues stop after adjustment, the fault is resolved.

## Brief Summary

- Timing should be considered **only after all other causes are ruled out**.
- Confirmation method: **Check whether the hook tip aligns with the needle eye at 202°**.
- Fix: **Loosen gear → align → tighten → test**.

If the problem persists after adjustment, check for a worn hook tip or incorrect needle bar height.
