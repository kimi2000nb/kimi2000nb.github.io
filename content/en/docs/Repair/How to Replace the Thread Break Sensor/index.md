# How to Replace the Thread Break Sensor

The **Thread Break Sensor** is an important part of the embroidery machine's thread detection system. It monitors the movement of the upper thread and helps the machine detect when the thread has broken, run out, or is not feeding correctly.

When the sensor detects a thread break, the machine can stop embroidery and alert the operator so the problem can be corrected before continuing.

## What Does the Thread Break Sensor Do?

The Thread Break Sensor monitors the upper thread during embroidery.

Its main functions include:

- Detecting when the upper thread breaks
- Detecting when the thread runs out
- Monitoring thread movement during stitching
- Stopping the machine when a thread-break condition is detected
- Helping prevent the machine from continuing to stitch without thread

## Symptoms of a Thread Break Sensor Problem

A faulty or incorrectly installed sensor may cause symptoms such as:

- The machine does not detect a thread break.
- The machine stops even though the thread is intact.
- The machine repeatedly reports a thread-break error.
- The sensor does not respond correctly to thread movement.
- The machine continues stitching after the upper thread has broken.

Before replacing the sensor, check that the thread is routed correctly and that there is no dust, lint, or debris interfering with the sensor.

## Important Note

After replacing the sensor, make sure it is installed in the correct position and that the thread passes through the sensor correctly.

Test the machine after installation to confirm that the sensor can correctly detect thread movement and thread breaks.

If the problem continues after replacing the sensor, check the thread path, sensor wiring, connector, and related machine settings.
